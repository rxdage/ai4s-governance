# 一个看起来整理过的文件夹，其中 87% 的名字 agent 读不懂

**English title:** A folder that looks organized, where 87% of the names are unreadable to an agent
**English hook:** Humans navigate by folders and memory. Agents navigate by names. A folder can look tidy to you and still be dark to an agent.

---

上周有人跟我说，他们的数据挺整齐的：按日期分文件夹，按项目分子文件夹，报告和原始数据分开。

我信。人看确实整齐。

然后我跑了一次 `ai4s audit`。

## 先看一个合成样本

我造了 115 个文件，把常见的命名习惯都放进去：

- `final_v2.csv`、`final_final.csv`、`copy of data.csv`
- `Channel_10_for_filterData_2026-07-22-17-00-31.csv`
- `R37_W1_D2__MEAS__NA__T202603041430_RUN0000.csv`
- `dna034.abf`
- `R0037-W01-01_after 丙酮擦拭.jpg`

结果：

```text
115 files, 15 parseable (13.0%), 5 duplicate name(s), 0 sidecar(s)
```

其中 87% 的名字，agent 打不开，就不知道它是什么。

最常见的四类问题：

| 错误 | 数量 | 例子 |
|---|---:|---|
| `CHARSET_INVALID` | 37 | 带空格、中文、连字符 |
| `ZONE1_SYNTAX` | 30 | `R37_W1_D2`，没有补 4 位 |
| `ZONE_COUNT` | 28 | `final_v2.csv`，根本不是四区 |
| `EXT_MISSING` | 5 | 名字后面没有扩展名 |

合成样本只能说明工具能抓到什么。真实数据呢？

## 再看两个真实目录

后来我们把样本扩到五个数据根：一份早期测试批次 171 个文件，只有 25.7%；两个 owner 的 `SR_DATA` 分别是 926 和 931 个数据文件，都是 100%；一份交付包 122 个数据文件，也是 100%。旧测试包还是 0%。

中间那个 25.7% 是“改到一半”的批次。在这几个样本里，改名更像二元状态：没改的落在 0–26%，改完的落在 100%。

还有一份 221 个文件的报告/配图包，0%。这个 0% 不算问题：它不是数据根，本来就不该按数据命名。判断一个目录值不值得治理，先看它是不是数据根。

这两组数字放在一起，才是重点：改名不是为了好看。它决定 agent 能不能读。

## 人靠文件夹，agent 靠名字

人找东西的路径通常是：项目 → 日期 → 批次 → 文件名。文件夹本身承载了大量上下文。

agent 没有这个路径。它拿到的是一个文件名，最多再加一个相对路径。它不会先问你“这个 `final_v2` 是哪个批次”，它只会打开，或者跳过。

所以会出现一种很奇怪的状态：

- 你打开文件夹，觉得井然有序；
- agent 打开同一个文件夹，觉得一片黑暗。

这不是谁更聪明的问题。是两套导航方式不一样。

## `ai4s audit` 看什么

它只看名字和大小，不读内容：

- 多少名字能按四区解析；
- 最常见的语法错误；
- 重复的完整文件名；
- 空格、中文、`final_v2`、无扩展名这些历史习惯；
- 先修哪三个。

它不能告诉你科学对不对，也不能告诉你两个码是不是同一个意思。那份报告只回答一个问题：**这些名字，机器能不能读。**

如果对方不方便给文件，只给一份 `names.txt` 也行：一行一个相对路径，不含内容。我拿它跑过 115 个合成文件，也跑过 931 个真实文件，结果一致。

## 先修三个

1. **去掉文件名主体里的空格和中文。** 目录名可以保留中文，文件名主体不行。
2. **选一个四区形状。** `R####_W####_D####__TYPE__COND__T##########_RUN####.ext`，四段缺一不可。
3. **每个文件都有扩展名。** 没有扩展名的文件，连“打开方式”都要猜。

然后拿 10–50 个文件试一次，不要一次全改。改完跑 `ai4s check`，看程序给不给你 PASS。

我不是说你的文件夹乱。我是说，对人整齐，不等于对 agent 可读。

想看看自己的目录是什么样：

```bash
ai4s audit /path/to/lab-data --label "Lab A" --out audit_report.md
# 或者只给名字清单
ai4s audit --names names.txt --label "Lab A" --out audit_report.md
```

报告不改任何文件。
