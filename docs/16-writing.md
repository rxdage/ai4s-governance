# 16 · 写给人的字：humanizer 清单

> 这份清单适用于所有给人看的东西：README、文档、field notes、发布说明、文章、邮件、群公告。
> **发布前必须过一遍。** AI 可以起草，但不能直接发模型原文。

## 为什么

模型写的东西有一种可辨认的形状：每段一个金句，每个小节先结论后解释，句子长度差不多，排比很多，破折号很多。读三篇就腻。

更要紧的是，这种文字会让读者觉得“你没在现场”。一个真跑过项目的人，会记得某个下午、某个文件名、某次吵架；模型不会。

Humanizer 不是把文字变油滑。是把它变回一个具体的人写的。

## 十个常见的 AI 腔

1. **“不是 X，而是 Y”反复出现。** 一篇里超过一次，就像模板。
2. **三段式排比。** “更快、更准、更便宜”——听着顺，但常常没有信息。
3. **每节都先给结论，再解释。** 真实的人会先讲一件事，再慢慢说出结论。
4. **抽象开头。** “随着 AI 的发展……”“在当今……”。删掉，直接从下午三点那个文件开始。
5. **“真正的/本质的/核心的/关键的”抬高普通观察。** 去掉这些词，句子通常还成立。
6. **每段一样长。** 人写东西会长短不齐，有时一句话就是一段。
7. **没有数字、没有文件名、没有动作。** 全是“提升了效率”“改善了体验”。
8. **没有犹豫。** 真实的人会说“我们当时也没想清楚”“这条不一定适合你”。
9. **过度使用破折号、粗体、冒号。** 一页里出现十次，读者会累。
10. **结尾一定要升华。** 不是每篇都需要“架构会过时，修理的顺序不会”。

## 八个改法

1. **从一个具体的下午/文件/对话开始。** 不要从定义开始。
2. **让句子长短不齐。** 允许一个六字句。允许一段只有两行。
3. **把“不是 X，而是 Y”改成直接说 Y。** 或者改成“X 不够。Y 更……”——但不能每段都这样。
4. **加一个只有你知道的细节。** 文件名、错误码、谁的哪句话、几点钟。
5. **删掉一个金句。** 留一个普通句子；普通句子更可信。
6. **加一句边界。** “这条不一定适合你”“我们当时也没量”“这个数字是重建的”。
7. **用“我/我们”和“你”。** 不要全程“本文”“该系统”“用户”。
8. **读出来。** 读到喘不过气的地方，删；读到像 PPT 的地方，改。

## 改之前 / 改之后

**改之前**

> Adoption is not “read the doc”. It is the first PASS, the first self-initiated check, the first receipt. We learned that the hard way.

**改之后**

> 我们一开始以为 adoption 是大家读过文档。后来发现，分界线是第一次拿到 PASS。那天之前，他还在旁边看；那天之后，这件事才变成他自己的。

**改之前**

> The strongest model is not the default for every edit. Route mechanical work to a cheaper harness and reserve the frontier model for judgment.

**改之后**

> 有一段时间，我们所有事都用最强的模型。贵，慢，还是错。后来把机械活挪到便宜一点的 harness，把判断留给强模型，才稳定下来。

**改之前**

> This report cannot tell you whether the science is right.

**改之后**

> 这份报告只能告诉你名字有多乱。它不知道你的科学对不对，也不知道两个码是不是同一个意思。

## 发布前检查

先跑检查器：

```bash
python scripts/humanize_check.py --path . --strict
```

它只抓最常见的形状，不判断好坏。`--strict` 只看 README、field notes 和 13–15；
其他文档是提示，不阻塞。某一行是故意的例外（引用、标题、反面例子），
在行尾加 `<!-- humanize:ignore: 原因 -->`，不要关掉检查器。

然后逐条过：

- [ ] 开头是一个具体场景，不是定义/趋势/口号。
- [ ] 全文“不是 X，而是 Y”不超过一次。
- [ ] 至少有一个数字、一个文件名或一个动作。
- [ ] 至少有一句“我们也没想清楚/不一定适合你/这是重建的”。
- [ ] 每段长度不一样；有一句话独立成段。
- [ ] 删掉了“真正的/本质的/核心的/关键的”里的一半。
- [ ] 破折号不超过三处；粗体不超过五处。
- [ ] 结尾没有强行升华。
- [ ] 读出来不喘。
- [ ] 给一个没看过背景的人读，他能复述“发生了什么、你做了什么、他该做什么”。

## 最后

如果一篇文字读起来像“一个模型在向另一个模型汇报”，就重写。

读者不需要你完美。读者需要知道你在现场。
