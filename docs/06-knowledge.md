# 06 · 知识与模型：卡片、指针、置信

> 数据治理回答“这个文件是什么”；知识治理回答“这句话凭什么可信”。
> 两者共用同一条纪律：**唯一真值 + 只增不改 + 作废留痕。**

## 1. 两种卡片，不要混

| | 数据文件 | 知识卡 | 模型卡 |
|---|---|---|---|
| 数量 | 百万级 | 几十篇 | 十几张 |
| 读者 | 机器为主 | 人为主 | 人与归因系统 |
| 命名 | 四区制 | `KB-<类>-<号>_<中文题>.md` | `MODEL-<场景><号>-<slug>.md` |
| 进库 | 进单源库 | 不进库；INDEX 登记 | 不进库；正本在代码仓 |
| 变更 | RUN+1 | 升版本 + changelog | 小修升版本；**推翻性修改必须新开编号** |

### 为什么知识卡不用四区制

四区制是给“机器生成、成千上万、只有机器读”的数据文件设计的。
知识文档是“人写的、几十个、主要给人读”，标题里的中文恰恰是最有价值的部分，
且一篇文档常跨多个批次，第 1 区根本写不下。

所以：**数据文件进库走四区；知识文档进知识库走 KB 编号 + 中文题。两套并行、各管各的。**

## 2. 知识卡

### 命名

```
KB-<类别>-<4位序号>_<中文短题>.md
KB-EDU-0001_从光电效应到报告判读.md
KB-MOD-0007_某仿真平台电容与电场.md
KB-PROC-0001_物理模型对外引用纪律.md
```

类别：

| 代号 | 收什么 |
|---|---|
| `EDU` | 原理讲解、判读教程、培训问答 |
| `MOD` | 仿真/计算模型的**模型卡**（正本在别处，这里只登记指针） |
| `SOP` | 可照着做的操作方法、判读清单 |
| `PROC` | 方法规程、引用纪律、作废清单 |

### 元信息块

```yaml
---
编号: KB-MOD-0007
标题: 某仿真平台：cell 级电容与电场 3D 模型
类别: MOD
owner: Li Ming
状态: 已验证（A 级为主，含 X 级作废项）
登记日期: 2026-03-04
正本: models/sim/
形态: COMSOL + Python
---
```

### 注册：INDEX 是唯一台账

- 写完卡 → 在 `INDEX.md` 加一行。**不在 INDEX 里的不算在册。**
- 状态两级：`草稿` →（owner 实名审一遍）→ `已审(姓名 日期)`。
- 培训与对外引用**以已审为准**。

### 模型卡只登记指针

模型本体不复制进知识库——正本在 git 仓/原仓库，复制会两处漂移。
模型卡写：正本路径、形态、能算什么、输入输出、验证状态、置信、边界。

## 3. 模型卡：八段，缺一不批

1. 物理出发点（第一性原理、**假设清单**、适用范围）
2. 模型推导（步步可复核）
3. 真实参数代入（数量级结果——没有数字的模型不收）
4. 对最终信号的预测（方向 + 公式）
5. 对表征结果的预测（逐项写，不敏感也要写明为什么）
6. 与其它模型及编码体系的接口
7. 可执行验证（脚本 + 判据）
8. 文献线索（方向性线索 + “待核对”标注；**禁止伪精确引用**）

两个分数（由评审人维护，不由作者自封）：

- **重要性 /10**：对良率/性能/成本的杠杆 × 在归因中被查询的预期频率。
- **置信 L0–L3**：
  - `L0` 推导自洽，未算数
  - `L1` 解析验证：数量级/量纲/极限行为自洽
  - `L2` 数值/仿真验证：脚本跑过，判据通过
  - `L3` 与自己的实测数据标定：必须引用具体批次/样品编号

**升级规则：L2→L3 必须在文档里引用具体数据编号；升级走评审，审批人是评审人。**
**没有一个模型达到 L3 是正常的**——公开案例里 15 个模型最高 L2，这比“全都已验证”诚实。

## 4. 引用纪律：A / B / C / D / X

模型卡里的数字，对外引用前先过一遍置信分级。这是整套资产里**最可迁移**的一份。

| 级 | 含义 | 准入门槛（全部满足） | 可以拿来做什么 | 绝不能做什么 |
|---|---|---|---|---|
| `A` | 数值实测 + 收敛 + 独立复核 | 真求解器解；有网格收敛指标（GCI）；有独立复算 ≤1% | 可作判据、**可直接对外引用**、可进回归门 | — |
| `B` | 真数值解，但收敛未做完 / 只有单一验证路径 | 真解、无失败，但缺 GCI 或独立复核之一 | 可作趋势、量级、相对比较 | 不作精确判据，**不写“±x%”** |
| `C` | 解析/闭式预测，未经数值验证 | 有完整推导与代入值，无对应数值算例 | 可作预期、设计参考、量级估计 | **不当实测引用** |
| `D` | 估计/文献量级/待核对 | 标 `[EST]` 或“待核对”，无 DOI，无实测 | 只作数量级 | 不进回归门、不进标定曲线 |
| `X` | **已作废**（保留作历史证据） | 已被后续工作证伪 | 只能用于回答“为什么这个说法错了” | **禁止引用为结论** |

三条配套规矩：

1. **本级别优先于原始文档里的自我评价。** 原报告写“已验证”不等于 A 级。
2. **A 级不等于“对真实器件准”。** A 只说明模型内部的数值不确定度小；
   叠加未知物理参数后，对真实器件的预测可能差一个量级。
3. **相对量比绝对量可信得多。** 同一张网格上相减能消掉大部分离散误差，
   `ΔC/C` 类结论常能到 A–B，而绝对值只到 A + 未知项。

### 五个灰度标记

可叠加在 A–D 上：`A[子集]`、`B[看门狗]`、`A[窄]`、`B[单点]`、`B[口径依赖]`。

**标记是引用条件，不是修饰词。** 括号里的限制没写进引用语境，这次引用就是错的。

## 5. 对外交付包（handoff）

给外部 AI/合作方一个“防幻觉包”，比给它一个文件夹有用：

| 文件 | 作用 |
|---|---|
| `CONTEXT_PACK.md` | 日常用的核心包：器件/夹具几何、血统数字、现行处方、未知项；每个数字带出处 |
| `ASSETS.md` | 资产置信分级表 + 作废清单 |
| `SYSTEM_PROMPT.txt` | 硬规则：先查作废台账、口径必须带全、不得把估计写成实测 |
| `DATA_INDEX.md` | 49 个数据表索引 |
| `GPT_GUIDE.md` | 怎么问、怎么引用 |
| `viz_demo.html` | 零依赖可视化原型，双击即开 |

规则：

- **口径规则写在最上面**：任何 C/G 数字都必须带（频率、网格档、掺杂档、面积/几何档）；
  不同口径的数字禁止直接相加或比较。
- **每个数字后面括号写出处**。
- **作废清单单独一节**，并明确“这些数字仍散落在哪些文件里”。
- 交付包是快照，不是真值；真值在台账和源文件。

## 6. 知识与数据的接口

- 模型卡第 6 节写“归因因子”：当归因排序把某个因子顶上来，查对应模型回答“物理上说得通吗、
  下一步验证实验是什么”。
- 模型结论落到具体批次/样品时，引用四区编号（`R0007_W0012_D0003`），
  归因系统才能把“结论”挂到“对象”上。
- 知识卡不复制数据，只引用编号；数据文件名变了（改名重入）要同步改卡片里的引用。

## 7. 检查清单

- [ ] 每张卡都有元信息块与 INDEX 一行。
- [ ] 状态只有“草稿 / 已审(姓名 日期)”两种。
- [ ] 模型卡八段齐全，含假设清单与可证伪判据。
- [ ] 引用数字带置信级别与口径；A 级带 GCI 与独立复算。
- [ ] 作废结论有 `superseded_by` 或台账条目。
- [ ] 对外包里的每个数字都能指回源文件。
