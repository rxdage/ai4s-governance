# 05 · 运行节奏：四夹制、巡检、回执与周复盘

> 治理最终是一组**有固定时刻、有固定产出、能回头看**的仪式，文档只是入口。
> 没有节奏的规范，三周后就会变成“大家都知道但没人做”。

## 1. 每个人的四个夹子

每人共享目录的**最外层只有四个夹**，全大写英文：

```
你的目录/
├── SR_DATA/    要进库的数据：累积制，只添不挪、永不清空
├── REGISTRY/   字典三件套的新增词条：纯增量，每轮清零
├── LIVEDOCS/   频繁更新的活文档本体：不入库，随便改
└── PERSONAL/   只给自己用：草稿、代码、日志、别人发来的文件
```

| 夹 | 放什么 | 增删口径 | 谁读 |
|---|---|---|---|
| `SR_DATA/` | 仪器原始采集；人写的、要被引用的（配方/协议/参数/报告/台账）；复核后的衍生数据 + sidecar | **累积制**：只添不挪、永不清空；增量由机器算，不由人挑 | 收库人扫 |
| `REGISTRY/` | 三件套 yaml 的**新增词条提案** | **纯增量**：每轮只放新增词条，已注册的一条不带 | 收库人拉取 |
| `LIVEDOCS/` | 台账、汇总表、跟踪表 | 天天改；某一版要被引用时，拷快照改四区名放进 `SR_DATA/` | 同事看现行版 |
| `PERSONAL/` | 草稿、代码、旧日志、中间结果 | 随意 | 没人扫、没人看，AI 也不碰 |

**两个“增量”口径是反的，别记混：**

| | 交什么 | 老的怎么办 |
|---|---|---|
| `SR_DATA/` | **全量攒在夹里**，新数据直接放进去 | **老文件一个不许动**——不挪、不删、不清空；收过的系统自动跳过 |
| `REGISTRY/` | **只交新词条** | 已注册进总表的条目**一条都不要再带**——带了就是“改已注册的码”，直接判 ERROR |

一句话：**数据夹越攒越多，字典夹每轮清零。**

为什么夹名全大写英文：命名规范禁止文件名出现中文；路径带中文在 scp/ssh 引号、
Windows 控制台编码上反复踩坑。夹子里面的结构**不规定，也禁止 AI 去整理**——
仪器导出的目录名本身是溯源信息（`CycleData_11_Time_2026-07-20-15-57-22` 带采集时刻），
拉平整理等于销毁信息。

## 2. 一天

| 时刻 | 谁 | 做什么 | 产出 |
|---|---|---|---|
| 11:30 | 机器 | 出机械草稿：环境、各人 REGISTRY 清单、分类、门禁原文、每人待入库/凭据/对账/抽查候选 | `intake_draft/latest.md` |
| 12:00 | 机器（规则放行） | **可放行候选**：凭据 PASS、清单与实物一致、快照 = 权威位、无任何一面旗 → 自动 `copy --apply` → `verify` → 写台账 → 回执卡进群 | 台账 + 回执 |
| 12:30 | 人 + AI | 字典侧：拉原文件、审提案、并入预览、把签字命令发给 Steward | 呈报 |
| 任意 | 人 | `sign --apply`、抽查、带旗批次的放行 | 签字 / 放行 |
| 17:30 | 机器 | 未接住日报：回执被拒、没听懂、🔴 群发满 3 天没答的题 | 私发 Steward |
| 17:40 | AI | 把未接住逐条分析到可以动手，备好卡与补丁，**停下等点头** | 分析 + 待发卡 |

**“规则放行”不是 AI 放行。** 它是人签过字的一条规则：
只有当凭据、清单、快照、旗子四样全部机械可判时，机器才执行复制。
带旗的（打回 / 待人判 / 知情收 / 没查成）一条不碰，私发 Steward。

## 3. 一周

| 时刻 | 做什么 | 产出 |
|---|---|---|
| 周一 08:00 | 巡检：每人待入库、缺凭据、ERROR、未答 WARN、字典滞留、开着的修订单/请求 | 人卡 + 群消息 |
| 每个工作日 | 收库（见上） | 台账 + 回执 |
| 周五 08:00 | 巡检（同周一） | 同上 |
| 周五 18:00 | **周总结**：这一周是在往前走，还是在原地把同一件事重做一遍？ | `周总结_YYYYMMDD.md` |

周总结固定七节，其中三节必须人写：

1. **数字**（照抄）：四周的“@机器人 / 接住 / 没接住 / 占比”。只看趋势，不对单周波动做文章。
2. **本周没接住的逐条**（照抄）：原话 + 派生事实。
3. **死法归类与判断**（人写）：把第二节逐条归进“哪一类死法”。类名沿用上一页，
   不要重起炉灶——类名一换，“这一类修没修”就再也看不出来了。
4. **复发**（照抄 + 人确认）：他可能又说了一遍。
5. **此刻开着的题**（照抄）：按挂了多久排；同一件事开着不止一道题的，要合并。
6. **上周说要做的，做了没**（人写）：打开上一页，逐条标 ✅/❌/🚫。
7. **这一周要定的事**（人写）：三五条封顶，每条一句话 + 一个明确动作。

> **第 6 节是整页的重点。** 没有“回头看上一页”，周总结也会变成新的重复劳动。
> 第一份周总结列了“删 7 条已并分支、移除 3 个 worktree”，挂到第二周一个没少，
> 就是因为没有任何一页会回头看上一页。

### 六类“没接住”的死法（真实统计）

| 类 | 一句话 |
|---|---|
| 手拼卡没底稿 | 他照卡回了，机器查不到这张卡问过什么 |
| 机器里没有那一岔 | 他答的是一条机器只认“已做/未做”的题 |
| 写了没人读 | 机器算出来了，下游没有消费者 |
| 格式 | 照卡回了，选项后面多写一句 → 整条拒收 |
| 提问/求助没接上 | 他贴报错、问一句，机器没答 |
| 不是答题 | 闲话、纠正称呼，不算缺陷 |

每一类右边写状态：✅ 关了（哪天、被什么关的、**之后 0 例**）/ ⚠ 没关（现在靠什么挡着）。

> **“之后 0 例”是这一页最值钱的一句话。** 它是“我们在往前走”唯一的硬证据——
> 没有它，所有关于“修好了没”的讨论都是感觉。

## 4. 回执卡

一轮收库发 **1 张总结卡 + 每人 1 张回执卡**；没收、无待办的也发绿卡（“没事也发卡”，
这样“没收到卡”本身就是一个信号）。

固定结构：

```
已入 SR（批次号）+ 有 N 项要你认领
图例：🔴 只能本人做或答 / 🟡 AI 能做
▶ 整张卡复制给你的 AI

已入库冻结：批次号、件数、在哪、verify、冻结含义
问题：编号、🔴/🟡、⛔、在哪、依据、谁来做、机器核
🟡 给你的 AI（对应问题号，末尾 ⛔ AI 不许做）
🔴 只有你能做的（每题 A/B/C 各一行）
下次巡检前在群里回的一段（照抄填空，一题一行，只认给定选项，不回 = 未做）
脚注：这是流程回执，不是 AI 动了你的夹
```

三条硬规则：

1. **卡只由工具发**，带底稿。手拼卡 = 没底稿 = 同事照卡回了也一律被拒。
   真实事故：两张手拼卡发出后，同事照卡填空回复，机器人整条拒收，
   还回了一句“那张卡还没群发”——号没抄错、卡也发了，**两句都不是事实，却把锅甩给了当事人**。
2. **一个题号只能配一个选项。** 要问两件事就拆成 `2a` / `2b`。
3. **发卡前先刷牌面。** 牌面是当天 08:00 的，收库发生在中午之后；
   中间几个小时里同事做掉的事、你刚收进库的文件，旧牌面都不知道。
   照它出卡就是催一件人家已经办完的事，比不发还糟。

## 5. 机器人的命令面

保持小。它只做“把一句话变成一条记录”和“解释一个词”。

| 命令 | 谁 | 效果 |
|---|---|---|
| `回执 <批次> <题号> <选项>` | 本人（Steward 可代填） | 记一条回执；只认给定选项 |
| `放行 <人> 依据 <一句话>` | Steward | 记放行意图，回三条现成命令 |
| `拒收 <人> <原因>` | Steward | 记拒收；本人没动之前不再报 |
| `豁免 <人> <短码> 到 <日期> <理由>` | Steward | 记一条有到期日的豁免 |
| `解释 <词>` | 任何人 | 查词表 |
| `状态 [人]` | 任何人 | 未回的题按“未做”显示 |

机器人不做的事：不签字、不复制、不改注册表、不替人答题、不主动 @ 人。

## 6. 指标

只看五个，不要造仪表盘：

| 指标 | 定义 | 健康信号 |
|---|---|---|
| ERROR 率 | 每次交付的 ERROR 数 / 文件数 | 逐月下降 |
| 一次通过率 | 首次自查即 PASS 的批次数 / 总批次 | 上升 |
| 未接住率 | 没接住的 @ 数 / 总 @ 数 | 下降 |
| 复发 | 同一类死法在“关闭”后再次出现 | **0 例** |
| 从交付到回执 | 中位小时数 | 稳定或下降 |

不要用“文件总数”“治理覆盖率”当 KPI：它们只会激励人把不重要的东西也塞进库。

## 7. 什么不该自动化

- **语义判断**：这个值对不对、内容对不对得上名字、这批该不该收。
- **抽查**：打开文件看。
- **签字**：哪怕 AI 能按，也不让它按。
- **发消息**：AI 可以起草，发送是人。
- **删除**：任何情况下都不自动。

```
每周一 08:00 巡检

每月最后一天 看趋势 + 关掉一类死法 + 写“之后 0 例”

```
