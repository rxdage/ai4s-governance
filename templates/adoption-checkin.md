# Adoption check-in（模板）

> 每两周一次，10 分钟。不要问“大家觉得怎么样”，问里程碑和卡点。
> 文件名：`ADOPT-YYYYMMDD.md`。

## 本轮数字

| 指标 | 本轮 | 上轮 | 备注 |
|---|---:|---:|---|
| 活跃人数 | | | 本周有交付/回执的人 |
| M1 第一个 PASS | | | 累计人数 |
| M2 自己发起自查 | | | 累计人数 |
| M3 第一次回执 | | | 累计人数 |
| M4 第一条提案 | | | 累计人数 |
| Time to first PASS（中位） | | | 从拿到包到凭据 |
| Rounds to first PASS（中位） | | | 跑了几轮 |
| WARN 答复延迟（中位） | | | 从发卡到答复 |
| 回执回复率 | | | 已回 / 已发 |
| 同类失败复发 | | | 关闭后再次出现 |

## 逐人

| 人 | 到哪一步 | 卡在哪 | 下周解锁什么 | 谁负责 |
|---|---|---|---|---|
| Owner A | M2 | 不敢点 `--apply` | 陪跑一次改名 | Steward |
| Owner B | M1 | 凭据快照对不上 | 重跑一次自查 | Owner B |
| Owner C | M0 | 觉得“又多一套规矩” | 用他自己的 5 个文件演示 | Champion |

## 三个问题

1. 这一轮有没有人**没人催**就跑了自查？如果没有，为什么？
2. 有没有人把 WARN 当“改掉就好”？他改了什么？
3. 有没有一条规则，三个人都问过同一个问题？如果有，改工具措辞，不要改人。
